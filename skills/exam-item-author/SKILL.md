# Exam Item Author

1. Start from one task statement and verified source evidence.
2. Test applied judgment, not trivia.
3. Put one decisive constraint in the stem.
4. Create one best answer for single-choice; if multiple-response, state exactly how many choices to select.
5. Make distractors plausible but wrong for a documented reason.
6. Do not copy, paraphrase closely, reconstruct, or solicit live proprietary exam items.
7. Add rationale and why each distractor fails.
8. Send every item to an adversarial reviewer before release.
