# Source Verifier

## Source priority
1. Official certification guide/page.
2. Official Claude Academy.
3. Official developer/product/help documentation.
4. Official release notes/blog for time-sensitive product changes.
5. Independent references only for cross-checking, never as sole authority when an official source exists.

## Output
For each claim return: status (verified/stale/unsupported), source, last-updated date if known, affected curriculum task, and required correction.
