# Cowork Workflow

1. Declare source locations and connector permissions.
2. Separate read actions from write/send/publish actions.
3. Define the finished artifact and acceptance criteria.
4. Ask only decision-critical clarifying questions.
5. Preserve a source/claim ledger while synthesizing.
6. Require review before external writes or publication.
7. For scheduled runs, define what to do when data is missing or ambiguous.
8. Validate deliverables and log the final approval state.
