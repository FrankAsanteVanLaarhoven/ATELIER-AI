# Claude Architect Digital Assessment Service — Blueprint v1.0

A production-oriented training, practice-exam, hands-on lab, case-study, and capstone module aligned to the public Claude Certified Architect — Foundations (CCAR-F) blueprint.

## Important scope
This package mirrors the **public exam structure, domains, weighting, and scenario style**. The practice questions are **original** and are not copied/leaked certification questions. This is necessary for IP integrity, exam security, and a commercially defensible digital service.

## Product modes
1. Learn — source-grounded lessons mapped to every task statement.
2. Drill — task/domain question sets with immediate explanations.
3. Mock Exam — 60 questions, 120 minutes, blueprint-weighted, no hints.
4. Scenario Lab — interactive architecture decisions with state and failure injection.
5. Case Studies — three end-to-end real-world deployments.
6. Capstone — design, implement, evaluate, govern, and present a production Claude system.
7. Agent/Skill Factory — create and validate reusable skills, agents, hooks, MCP integrations, and harnesses.
8. Slides/Design Studio — build evidence-linked executive/technical decks using Claude Slides/Design conventions.

## Files
- `content/source_register.md` — extracted video facts + current official resources.
- `content/curriculum_map.md` — full domain/task curriculum and extended product tracks.
- `exam_engine/exam_blueprint.md` — assessment design and scoring.
- `exam_engine/question_bank.json` — 90 original scenario questions with keys/rationales.
- `exam_engine/generate_exam.py` — creates a 60-question mock from the seed bank.
- `case_studies/*.md` — three practical case studies.
- `capstone/capstone.md` — capstone brief and 100-point rubric.
- `skills/*/SKILL.md` — reusable skill definitions.
- `agents/agent_catalog.yaml` — role-separated agent design.
- `harness/harness_spec.md` — deterministic/agentic orchestration and eval harness.
- `product/service_blueprint.md` — digital service architecture, user journeys, data model and APIs.
- `governance/quality_security.md` — content provenance, security, anti-leakage and release gates.

## Commercialization note
Do not market this as an Anthropic-endorsed or official certification unless separately authorized. Market it as an independent exam-preparation and applied architecture assessment service aligned to the public CCAR-F blueprint.
